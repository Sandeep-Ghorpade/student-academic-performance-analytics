# Student Academic Performance Analytics

## Project Overview

Student Academic Performance Analytics is an end-to-end Data Analytics project developed to analyze academic performance, attendance, study habits, and demographic characteristics of students.

The project uses a dataset containing 5,000 student records and 23 attributes. Python and Pandas are used for data loading, cleaning, validation, exploratory data analysis, statistical analysis, and visualization.

MySQL is used to perform structured SQL-based analysis, while Power BI is used to build an interactive dashboard that allows users to explore student performance using filters such as department, gender, and grade.

The project demonstrates how raw student data can be transformed into meaningful analytical information through a complete data analytics workflow.

---

## Project Objectives

The main objectives of this project are:

- Load student data from a CSV dataset.
- Understand the structure and characteristics of the dataset.
- Inspect data types and statistical information.
- Identify missing values.
- Handle missing values appropriately.
- Detect duplicate records.
- Validate important numerical columns.
- Analyze student distribution across departments.
- Analyze gender distribution.
- Analyze academic performance.
- Analyze attendance patterns.
- Analyze study-hour patterns.
- Analyze grade distribution.
- Identify top-performing students.
- Identify students with low attendance.
- Analyze relationships between different academic variables.
- Perform SQL-based analysis using MySQL.
- Build an interactive Power BI dashboard.
- Extract meaningful insights from the dataset.
